# Wall Decores — Vector Showcase · Storyboard

**60 s · 60 fps · 1920×1080 · 3,600 frames · silent** · Composition: `VectorShowcase`

Built on the **VectorFilm** language (a one-point-perspective room drawn in line, then filled with flat colour; a visible brush paints the canvas stroke by stroke), taken further:

- **One room, dressed five times.** A paint roller re-colours the back wall, side walls and ceiling follow, and the pillows, rug and curtains re-tint.
- **The old painting is gessoed over** by a white-loaded brush before the new subject is painted.
- **The colour story is explained live** in the right-hand column: room swatches vs painting swatches with hex codes, a stroke counter, and a hue wheel that shows the colour harmony.
- **The camera pushes in** to the canvas while the brush works, then pulls back, and a picture light switches on when the painting is finished.

Layout: the room sits in a rounded window on the left (840 px). Text lives on clean cream on the right (760 px column). Text never sits on top of the illustration.

Type: Inter 800 (headlines, 96 px), Instrument Serif italic (accent lines, 104 px; painting titles, 54 px), JetBrains Mono (labels, 18–22 px). Nothing is smaller than 18 px. Easing: brand `cubic-bezier(.22,1,.36,1)`.

The rule throughout: the painting takes the wall's opposite (or a triad partner) as its hero colour, and the room's soft furnishings pick that colour back up, so wall, art and furniture read as one composition.

## Code map

```
src/vectorshowcase/
  VectorShowcase.tsx      master composition + HUD + paper grain
  theme.ts                timing, layout, type scale, the five room palettes
  motion.ts               room colour state per frame (roller / tint), hue maths
  paint/kit.ts            brush mark types, shape helpers, stroke scheduler
  paint/paintings.ts      the five paintings, as brush marks
  paint/PaintedCanvas.tsx renders a painting at any frame (wash / reveal / line / dots)
  paint/Brush.tsx         the visible brush, riding the active stroke
  room/ShowRoom.tsx       room structure, roller, furniture, canvas, gesso, picture light, camera
  text/Panels.tsx         BUILD column + per-room column (palette, stroke counter, hue wheel)
  text/Compose.tsx        five-room palette board
  text/Brand.tsx          brush wordmark (open + sign-off), contacts
```

The room geometry and line-drawing primitives come from `src/vectorfilm/room/`.

Render: `.github/workflows/render-vectorshowcase.yml` renders six 600-frame chunks on parallel runners (h264, CRF 18, muted), joins them with the ffmpeg concat demuxer using `-c copy`, and uploads the result as the `final-video` artifact.
